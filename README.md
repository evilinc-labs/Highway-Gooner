## Dependencies & Mods
- [Fabric loader v0.16.12](https://fabricmc.net/) or later.
- [Meteor Client build 1.21.5 - 52](https://meteorclient.com/), found in their archive.
- [Baritone 1.14.0](https://github.com/cabaletta/baritone/releases/).  Requires both api and standalone fabric jars. 
- [Gradle v8.14](https://gradle.org/) or later, required to compile.
- [ViaFabricPlus](https://modrinth.com/mod/viafabricplus), use Minecraft version 1.20.5 - 1.20.6 for builder to function.


## Module
- Highway Gooner (Wallbuilder)

## Main Features
- Can goon in all 8 directions within up to a 7 block diamater before moving.
- Utilized legacy rotations to place quickly and efficiently.  This may break in future 2b2t updates.
- Uses AirPlace if regular block placement failed.

## How to use
- Set **ViaFabric** to 1.20.5-1.20.6.
